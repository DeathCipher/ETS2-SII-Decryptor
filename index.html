      How this works
      
Some SCS Software files are stored in an encrypted container that starts with the signature ScsC: a 32-byte HMAC, a 16-byte AES initialization vector, the decoded size, then AES-256-CBC encrypted, zlib-compressed SiiNunit text.

      
The key has been public since the community SII_Decrypt project documented it, and every open-source decoder uses it. This page repeats that process with your browser's built-in Web Crypto API.

      
Plain-text files are returned as they are. Unencrypted binary (BSII) files are detected, but converting them to text needs a larger decoder than this tool includes, so you get the raw bytes.
